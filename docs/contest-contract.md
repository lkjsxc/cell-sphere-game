## Binding facts observed

- Deadline: **2026-09-13 (Sunday)** (the page reports an extension).
- Division: Web Page category, ZEN University application path.
- Work must be an animated page made with HTML/CSS/JavaScript.
- External libraries are prohibited except Bootstrap/Tailwind without further
  consultation. This project uses neither and has no runtime dependency.
- Originality and copyright-clean code/media are required.
- Submit a public GitHub repository and a hosted URL with matching behavior.
- Judging uses desktop and smartphone Google Chrome.
- Evaluation includes code/folder quality, readable comments, effective GitHub,
  tests, few bugs, fit/refinement/first-user clarity, and originality.

The page also notes that the ZEN University Web Page application form was still
being prepared on 2026-07-30; this must be checked before submission.

## Project interpretation

- Static repository-relative deployment; no external request after load.
- Native CSS/JS, procedural/authored visuals, system fonts, no copied media.
- Canonical identifier/tagline on title, metadata, README, and deployment.
- Real WebGL2 Chrome evidence plus an honest Canvas fallback.
- English canonical UI; complete Japanese localization remains incomplete.
- No analytics/account/network progression; browser-local data only.
