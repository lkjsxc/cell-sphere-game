## 2. Why this campaign was selected

The immediately preceding campaign already implemented most of the broad "autonomous World feel" request:

- old approximately `4×` pacing became normal `1×`;
- direct globe manipulation gained bounded release inertia;
- Home and World gained calm automatic orbit after inactivity;
- responsive framing became projected-geometry based;
- Result gained a nonnumeric World-cycle continuation ring;
- Home copy now communicates autonomous incremental play;
- a follow-up commit repaired flick velocity under delayed input delivery.

Reimplementing those systems would create rework and regression risk.

The post-campaign user policy nevertheless conflicts with three current production values:

- the current public ladder is `[0.5, 1, 2]`, not the requested six values;

- the current wide-layout center reaches approximately `70%` of usable width, while the requested composition is around a `2:1` left/right division, or approximately `66.7%`.

These conflicts share the same presentation-policy, responsive-browser, settings, documentation, and deployment verification boundary. They can be closed without changing simulation or renderer authority.
