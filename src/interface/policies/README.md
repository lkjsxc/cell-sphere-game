# Interface policies

Pure coordination policies for the stable scene selector, one bounded detail
shell, safe globe framing, terminal actions, and atomic world replacement.

- `progression-spheres.js` is the interaction source of truth: first activation
  selects; only a later activation of the same selected ready Evolution cell buys
  one level. It shares exact purchase authority with the detail button/semantic
  tree and rejects stale expected level/meta revision.
- `run-result.js` couples SCORE v4, exact Echo reward, History schema 6,
  Environment frontier, Trophies, and result idempotency.
- `run-session.js` owns first-wins teardown, presentation retirement, typed blank
  installation, and run-protocol-v5 startup.
- `surface-coordinator.js`, `scene-selector.js`, and `layout-policy.js` own shell,
  focus, keyboard, safe-area, and scene behavior without moving the globe.
- `continuation.js` and `new-world-surface.js` coordinate result continuation and
  explicit abandonment; neither spends Echoes or skips the unlocked frontier.
- `time-dial.js` exposes 1×/2×/4×/8× plus visible developer 16×–256× while every
  authoritative tick still executes.
- `trophy-notifications.js`, `trophy-surface.js`, and `presentation-timing.js`
  provide bounded, accessible, authority-neutral recognition.

There is no active Adaptation policy or presentation queue. Archived Adaptation
records are inert. These modules never mutate simulation authority. Gates include
policy/state-machine unit tests, transaction integration tests, real pointer/
touch/keyboard browser scenarios, and `audit:evolution-levels`.
