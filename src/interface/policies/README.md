# Interface policies

Pure coordination policies for the stable scene selector, single nonmodal
surface shell, safe globe framing, and the untouched-only result countdown. `adaptation-effects.js` bridges authoritative
selection messages to bounded presentation-only cell waves and captions.
`run-session.js` owns first-wins atomic world replacement, complete presentation
retirement, typed blank installation, and authority startup. `run-result.js`
creates an idempotent Echo/Imprint/History/Trophy transaction; the controller
persists its returned documents. `presentation-timing.js` centralizes UI-only
2.7 s toast, 3.75 s Adaptation, and 4.2 s Trophy durations. Its FIFO generation
tokens, duplicate suppression, and hold leases serve queued captions and the
persisted global Trophy presenter; world retirement clears only run-owned
captions. These policies never mutate simulation authority.
