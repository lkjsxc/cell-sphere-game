# src/game/trophies/

Pure mastery content, facts-v3 projection, deferred evaluation, migration
vocabulary, and cellular Trophy Sphere presentation.

Six family modules author exactly 16 current criteria each. Conditions use a
small frozen combinator schema (`at-least`, `includes`, `all`, `any`) over the
whitelist in `keys.js`; catalog validation rejects unknown keys, deep/empty
combinators, duplicate IDs/cells, and malformed thresholds. `facts.js` retains
bounded deterministic completed-world proof. `evaluator.js` persists maxima,
cumulative totals, masks, and card diversity exactly once per result and is
never called by storage load or validation.

`reach-river-touch` exists only in the explicit Legacy catalog. Schema-7
ownership migrates there; the distinct current `reach-lake-network` ID requires
hard whole-cell lake mastery. Facts-v1 water bit 2 is masked and cannot produce a
current lake award. Every other recognized old current ID is grandfathered.

`atlas.js` maps 96 current Trophies to six connected constellations on a
162-cell level-2 sphere; 66 neutral cells stay noninteractive. Trophies are
recognition only: they alter no simulation trait, SCORE, Echo income, or RNG.
