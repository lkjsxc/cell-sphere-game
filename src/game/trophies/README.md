# src/game/trophies/

Pure achievement content, proof projection, deferred evaluation, and cellular
Trophy Sphere presentation.

The six family modules author exactly 16 criteria each. `facts.js` retains only
bounded deterministic proof from completed worlds. `evaluator.js` is monotonic
and is never called by storage load or validation. `atlas.js` maps 96 trophies
to six connected constellations on a 162-cell level-2 sphere; neutral cells stay
noninteractive. Trophies are recognition only: they alter no simulation trait,
score, Echo income, or random stream.
