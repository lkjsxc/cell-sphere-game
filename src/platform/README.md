# src/platform/

Small browser adapters that degrade honestly when APIs or storage are absent.

| Module | Responsibility |
|---|---|
| `capabilities.js` | WebGL2, Worker, device, sharing, and DPR hints. |
| `settings.js` | Schema-3 durable preferences; Automatic choices, continuation, rotation off. |
| `storage.js` | Schema-5 Echo/Memory progression and level-3 morphology-fossil migration. |
| `history.js` | Schema-2 semantic archive, 24/32 worlds, 80 events/run, 700 KB cap. |
| `recent-runs.js` | Native IndexedDB visual bundles, newest ten, strict `INHV` validation. |

Progress migration validates schema-4 ownership before stamping graph 3,
quarantines unknown IDs, preserves Echo totals, and projects old edge Imprints
to bounded atlas cells. Semantic History stores stable event keys and up to
eight primary cells. Approximate visual detail is a separate, device-local
IndexedDB cache and is not part of JSON export/import. Every adapter returns
truthful success and keeps the current session playable when persistence is
absent or corrupt.
