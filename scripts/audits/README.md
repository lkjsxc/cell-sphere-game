# Production audits

Deterministic Node audits import production topology, compilers, simulation,
transactions, scoring, persistence, and render projections. They do not maintain
a copied balance model. Machine-readable output is bounded and written under
ignored `reports/`; reports never become simulation inputs.

Canonical endless-progression gates:

| Command | Source / authority checked |
|---|---|
| `audit:evolution-levels` | `skill-audit.mjs`: frequency-5 252 cells, sparse exact levels, 17,820 Level-1 breadth, Potential v3, repeat costs, Builds/mastery, migration, bounded cache/compiler. |
| `audit:environment-levels` | `environment-level-audit.mjs`: unlimited direct challenge compilation, onboarding protection, finite/monotone pressure, event/terminal bounds. |
| `audit:luminous` | `luminous-audit.mjs`: authoritative whole-cell charge, production/decay/zero, mastery, WebGL/Canvas semantics, no wires. |
| `audit:progression-numbers` | `progression-number-audit.mjs`: exact bigint/canonical decimals, malformed and huge values, debit/credit/hash/round trips, `2^53` boundaries. |

Ecology, SCORE, event, habitat, transformation, REACH, Trophy, campaign, and
lake audits remain focused production evidence. `terminal-soak.mjs` runs bounded
parallel production campaigns through exact result/persistence/History authority,
replays every result receipt, and reports heap, History bytes, and receipt bounds.
`adaptation-removal-audit.mjs` is a negative source gate: active Adaptations stay
retired while archived migration/History records remain inert. The 642-cell
manifest is migration evidence only, never current Evolution topology or economy.
Long fair-agent and untouched-cohort gates are `agent:long` and
`balance:holdout`.
