# Production audits

Deterministic Node audits import production topology, compilers, simulation,
transactions, scoring, persistence, and renderer projections. They do not
maintain a copied balance model. Machine-readable output is bounded and written
under ignored `reports/`; reports never become simulation inputs.

| Command | Source / authority checked |
|---|---|
| `audit:evolution-levels` | Current Evolution vector, exact levels/costs, Builds/mastery, bounded compiler cache, and graph invariants. |
| `audit:environment-levels` | Unlimited direct schedule compilation, finite monotone chronic pressure, Level-0 reset, and terminal bounds. |
| `audit:no-disaster` | Removed event/crisis modules and forbidden authority fields are absent while semantic History records remain allowed. |
| `audit:luminous` | Authoritative whole-cell charge, production/decay/zero, mastery, WebGL/Canvas semantics, and no wires. |
| `audit:progression-numbers` | Exact bigint/canonical decimals, malformed and huge values, debit/credit/hash/round trips, and `2^53` boundaries. |

Resource, freshwater, SCORE, habitat, transformation, REACH, Trophy, campaign,
and lake audits remain focused production evidence. `terminal-soak.mjs` runs
bounded parallel production campaigns through exact result/persistence/History
authority, replays every result receipt, and reports heap, History bytes, and
receipt bounds. `adaptation-removal-audit.mjs` is a negative source gate: active
Adaptation authority remains absent. Long fair-agent and untouched-cohort gates
are `agent:long` and `balance:holdout`.
