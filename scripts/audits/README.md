# World audits

Deterministic, non-runtime Node audits for terminal reliability, graph-native
event fields, connected whole-cell lake distributions, the complete 642-cell
Evolution economy, and all 96 Trophy proof boundaries. The lake audit measures
count, area, connectivity, separation, shore/wetland ecology, type/salinity,
coverage, deterministic hash, and generation time over 500 seeds by default.
The cell-visual source audit prevents fine world-surface geography from
returning. Outputs are written under ignored `reports/` and never become
simulation inputs.
