# assets/

Original local assets only. Everything in this directory is hand-authored or
generated by this repository's own scripts — never downloaded.

| File | Purpose |
|---|---|
| `mark.svg` | Project mark: network lines crossing a sphere. Used as favicon and in the share card. |

Invariants:

- No binary media committed unless generated by a committed script.
- No font files, icon packs, samples, or third-party imagery — the app
  renders everything procedurally.
- Keep total asset weight tiny (a few KB).
