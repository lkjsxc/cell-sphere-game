# assets/

Original project assets only. Everything in this directory is hand-authored,
generated by this repository, or captured from the project itself — never
downloaded.

| File | Purpose |
|---|---|
| `mark.svg` | Project mark: network lines crossing a sphere. Used as favicon and in the share card. |
| `cell-sphere-game-home.png` | Representative Home capture shown in the repository README. Documentation only; not loaded by the application. |

Invariants:

- Runtime imagery stays hand-authored or procedural; documentation captures are
  not application dependencies.
- Keep captures representative and intentionally curated. Generated browser
  evidence and contact sheets stay in ignored reports.
- No font files, icon packs, samples, or third-party imagery.
- Keep runtime asset weight tiny.
